Política de Privacidade

Lançamento de Finanças Pessoais · atualizada em 18/10/2026

Quem usa

Este aplicativo é de uso pessoal do seu criador. Ele não é oferecido ao público.

Quais dados o app acessa

Com a permissão dada na tela de login do Google, o app lê e grava somente na planilha do Google Sheets que o próprio usuário escolhe nas configurações. O acesso usa o escopo https://www.googleapis.com/auth/spreadsheets.

Onde os dados ficam

  • Os lançamentos ficam na planilha do usuário, na conta Google dele.
  • No aparelho ficam apenas: as configurações do app, uma cópia da última leitura da planilha (para funcionar sem internet) e os lançamentos que ainda não foram enviados.
  • Não existe servidor do app. Nenhum dado é enviado ao criador do app ou a terceiros.

O que o app não faz

  • Não vende, não compartilha e não transfere dados para ninguém.
  • Não usa publicidade, rastreamento ou estatísticas de uso.
  • Não usa os dados do Google para treinar modelos de inteligência artificial.

Leitura de notas fiscais

A leitura da foto de uma nota é feita dentro do próprio aparelho. Existe uma opção, desligada por padrão, para o usuário usar a própria chave de API da Anthropic. Se ele ligar essa opção, a foto da nota é enviada para a Anthropic apenas para ler o texto dela. Nenhum dado da planilha é enviado.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como apagar ou revogar

O acesso pode ser cancelado a qualquer momento em myaccount.google.com/permissions. Desinstalar o app (ou limpar os dados do navegador, no computador) apaga tudo o que ficou no aparelho. A planilha continua sendo do usuário.
